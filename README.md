# Rudolf Steinerskolan: портфолио-концепт

Неофициальный редизайн сайта школы [rudolfsteinerskolan.se](https://rudolfsteinerskolan.se/). Это не официальный сайт школы. Тексты и фотографии принадлежат школе и людям на снимках.

- `site/`: готовый сайт, откройте `site/index.html`
- `tools/`: сборка, запуск `python build.py` из этой папки
- `content/`: исходные тексты страниц
